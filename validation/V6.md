# V6 measured: repeat-test scatter from 8 NHTSA full-frontal pairs

Task t-20261121-183739, 2026-11-21. Replaces the remembered V6 figures in `docs/STAGE6-M4-M5.md` with numbers measured from raw NHTSA data. Nothing here ran the simulator or touched test B's pulse (`validation/test-b.*`); the raw files under `reference/nhtsa-pairs/` were only read.

## Commands

From the Broadsword root (in this task's worktree the script path is `validation/v6_scatter.py` and the folder `../../../reference/nhtsa-pairs`; the output is identical):

```
python -I projects\crash-sim\validation\test_v6_scatter.py -v
python -I projects\crash-sim\validation\v6_scatter.py reference\nhtsa-pairs
```

The second command exits 0 and printed the block under "Full output" below, unedited. The script re-checks every zip's sha256 against `reference/nhtsa-pairs/SOURCES.md` before using it and exits 2 on a mismatch; it passed for all 16. The `files` lines in the output give, per test, the zip sha256 (equal to the SOURCES.md value), the sha256 of the `.EV5` specification file inside the zip, and the sha256 of the channel file used. A separate `sha256sum` of each extracted `reference/nhtsa-pairs/<tstno>/v0<tstno>.EV5` equalled the EV5 value printed for its zip member, for all 16.

## Method (what the script does)

- Reads each test's zip with `convert.py`'s EV5 and channel parsers and its axis/unit tables (G'S times 9.80665 to m/s^2, XG axis, time column checked against NFP and DELT, `NFP <= 0`, point count checked against NFP/NLP). `convert.py` is unchanged. Its `build()` is not used: it refuses titles not starting "NCAP - " and only knows the codes FLLR and FLRR.
- Metrics follow `docs/STAGE6-M4-M5.md` lines 81 to 84 (quoted in the script's docstring) and are ports of `src/pulse.rs`: CFC filter over the whole record (J211 phaseless 4-pole Butterworth); delta-V = minus the trapezoid integral of the CFC 180 acceleration over [0, 0.15 s] (includes rebound); peak = most negative CFC 60 value in the window and its time; OLC (65 mm free flight, 235 mm restraint) of the CFC 180 pulse with v0 = CLSSPD / 3.6. Window 0.15 s (`--pulse-window 0.15`, line 151). Time zero is the database's index 0.
- Pair difference: |a - b| / mean(a, b) for delta-V, peak and OLC; absolute milliseconds for time of peak. This is the difference between the two tests, not a coefficient of variation: for two tests the sample CV is that difference divided by sqrt(2).
- Median and max are over the counted pairs.

## Channel per test

The brief asks for the rear-seat crossmember X acceleration, the same kind in both tests of a pair. Every test has a right-rear seat accelerometer (global X, G'S, DASTAT AM), so all 16 use it; the left-rear one was not needed. SENATT codes differ by era: FLRR (2010 NCAP tests, instrument comment "RIGHT REAR SEAT CROSSMEMBER X"), SERR (comments "ACC. #2 RIGHT REAR X", "V1 RIGHT REAR #2X", or none) and DSRR (no comment). SERR and DSRR are taken as the same right-rear seat accelerometer on the strength of those comments and their position in the channel list (right-rear follows left-rear in every test); the Guide's SENATT table was not read in this task, so that equivalence is an inference, not a quoted definition. The vehicle CG channel (VECG) exists only in 5036, 5061 and 5073 and was not needed. Curve numbers and codes are in the output rows ("channel curve N CODE").

## Which pairs counted, and why

Rule (in `v6_scatter.py`, printed in the output): same model year, mass within 5% (the brief's number), and VEHICLE fields 13 and 14 within 5%. Fields 13 and 14 are read as the two long dimensions in mm (for example the CTS pair 2885/4825 and 2880/4820); the Guide's field names for them were not read here either. Body-style code and make/model codes are printed for every pair but are not part of the rule.

All 8 pairs counted. Pair 3 (5061 body PU, 4240 body EX; model codes 44 and 43): mass differs 2.5%, the two dimensions 0.3%, so the same truck structure. Pair 8 (3915 body EX, 5073 body 4P; same model code 24): mass 0.9%, dimensions 0.1%. For both, body codes differ, so the summary is also printed for the six pairs with identical body codes (1, 2, 4, 5, 6, 7): its medians and maxima equal the all-pairs ones except time of peak (median 4.600 vs 4.175 ms), so counting pairs 3 and 8 changes no maximum. Pair 6 (Kia Forte: 6736 a 35 mph NCAP test, 6766 a load-cell-barrier test) has dim14 2.0% and counted. A stricter 2% rule dropped it in a first run; that rule was not in the brief and excluded a same-model, same-body pair, so it was replaced by the 5% one.

## Limits of this measurement

- 8 pairs, so a maximum over 8 values is itself noisy; pairs differ in era, barrier (NCAP rigid barrier, or the load-cell barrier used in the older Trailblazer, Ram, Tundra and Kia Forte second tests) and sample rate (20 kHz, 12.5 kHz, 10 kHz). Pairs 2, 3, 6 and 8 mix an NCAP test with a flat-load-cell-barrier test.
- One channel per test (right-rear seat crossmember), not the vehicle CG.
- Time of peak is the time of the global CFC 60 minimum inside the window, so a pulse with two similar peaks can flip between them.
